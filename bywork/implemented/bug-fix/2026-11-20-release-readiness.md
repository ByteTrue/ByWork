# 发布前接入与流转核对

Status: implemented

## 问题

记录流转需要支持自引用，目标尚未写入时不能把自身误报为死链。1.x 项目的 work/memory 记录含有状态、证据和长期约束，更新技能包不能代替项目记录的语义迁移。发布验证需要覆盖实际提交文件和安装产物。

## 决策

路径预检接受目标记录引用自身，继续拒绝真正缺失的其他目标。初始化保留原件，识别旧布局并提示迁移；[接入说明](../../../skills/bw/references/onboard.md)规定原件备份、未完成验收与现行约束的承接、链接修复和最终检查。

四态、6+2 行动与单 CLI 保持既有契约；旧记录和封存正文保留。机械检查只证明结构与已测试行为，不证明模型长期遵循。

## 备选方案

自动按旧目录名决定新状态可以减少整理操作，但目录名无法决定当前有效范围与未完成验收，因此迁移由模型依据原文和产物判断，CLI 负责结构校验。仅补充说明无法解除自引用的实际阻塞，因此同时修复共用路径检查。
